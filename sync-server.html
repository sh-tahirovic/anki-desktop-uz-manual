Oʻz serveringizdagi sinxronlash serveri

AnkiWeb'dan foydalana olmaydigan yoki foydalanishni xohlamaydigan ilgʻor foydalanuvchilar oʻrniga oʻz serveridagi (self-hosted) sinxronlash serveridan foydalanishi mumkin.

Eʼtibor berish kerak boʻlgan narsalar:

  • Bu ilgʻor funksiya boʻlib, tarmoq va buyruq satri bilan ishlashni yaxshi biladigan foydalanuvchilarga moʻljallangan. Undan foydalansangiz, oʻzingiz duch kelgan har qanday sozlash/tarmoq/firewall muammolarini mustaqil hal qila olishingiz kutiladi va undan foydalanish toʻliq sizning javobgarligingizda.
  • Yangiroq klientlar sinxronlash protokolidagi oʻzgarishlarga bogʻliq boʻlishi mumkin, shuning uchun Anki klientlaringizni serverni ham yangilamasdan yangilasangiz, sinxronlash ishlamay qolishi mumkin.
  • Uchinchi tomon sinxronlash serverlari ham mavjud. Ularga qarshi sinov oʻtkazilmaydi va sinxronlash protokoli oʻzgarganda ular yetib olishi uchun vaqt ketadi, shuning uchun ular tavsiya etilmaydi.
  • Anki ichidagi xabarlarda, hatto maxsus server sozlangan boʻlsa ham, "AnkiWeb" atamasi ishlatiladi (masalan, serveringiz ishlamayotganda "Cannot connect to AnkiWeb").

Installing/Running (Oʻrnatish/ishga tushirish)

Serverni oʻrnatish va ishga tushirishning turli usullari bor. Quyidagilardan birini ishlatishingiz mumkin:

  • Anki'ning kompyuter versiyasiga kiritilgan sinxronlash serveri
  • Anki'ning GUI bogʻliqliklarini oʻz ichiga olmagan alohida minimal sinxronlash serveri. Python va Rust tatbiqlari mavjud.

From a Packaged Build (Tayyor paketdan)

Bu Anki'ning kompyuter versiyasiga 2.1.57+ versiyasidan boshlab kiritilgan sinxronlash serveridan foydalanadi.

Windows'da cmd.exe sessiyasida:

set SYNC_USER1=user:pass
"\Program Files\anki\anki-console" --syncserver

Yoki MacOS'da Terminal.app'da:

SYNC_USER1=user:pass /Applications/Anki.app/Contents/MacOS/anki --syncserver

25.07 dan 25.09.4 gacha boʻlgan versiyalar uchun 'anki' oʻrniga 'launcher' ni yozing.

Yoki Linux'da:

SYNC_USER1=user:pass anki --syncserver

With Pip (Pip bilan)

Kompyuter versiyadagi Anki'ning GUI bogʻliqliklarini yuklab olmaslik uchun, PyPI dan yuklab olingan Python paketi yordamida mustaqil Anki sinxronlash serverini ishga tushirishingiz mumkin. Python 3.9+ oʻrnatilganiga ishonch hosil qiling.

python3 -m venv ~/syncserver
~/syncserver/bin/pip install anki
SYNC_USER1=user:pass ~/syncserver/bin/python -m anki.syncserver

With Cargo (Cargo bilan)

Anki 2.1.66+ dan boshlab, quyidagi buyruq yordamida mustaqil sinxronlash serverining Rust tatbiqini qurishingiz mumkin. Rustup oʻrnatilganiga ishonch hosil qiling.

cargo install --locked --git https://github.com/ankitects/anki.git --tag 25.02.5 anki-sync-server

25.02.5 oʻrniga Anki'ning eng yangi versiyasini qoʻying.

Protobuf (protoc) oʻrnatilgan boʻlishi kerak.

Qurilgandan keyin uni quyidagi bilan ishga tushirishingiz mumkin:

SYNC_USER1=user:pass anki-sync-server

From a source checkout (Manba kodidan)

Anki repozitoriyasini GitHub'dan klon qilgan boʻlsangiz, oʻsha yerdan oʻrnatishingiz mumkin:

./ninja extract:protoc ftl_repo
cargo install --path rslib/sync

With Docker (Docker bilan)

Foydalanuvchi qoʻshgan Dockerfile va baʼzi koʻrsatmalarni bu yerda topishingiz mumkin.

Multiple Users (Bir nechta foydalanuvchi)

SYNC_USER1 birinchi foydalanuvchi va parolni belgilaydi va oʻrnatilishi shart. Bir nechta hisob sozlamoqchi boʻlsangiz, ixtiyoriy ravishda SYNC_USER2, SYNC_USER3 va hokazolarni belgilashingiz mumkin.

Hashed Passwords (Xeshlangan parollar)

Ilgʻor foydalanuvchilar oddiy matnli parollar oʻrniga xeshlangan parollardan foydalanishni xohlashi mumkin. Buni qilmoqchi boʻlsangiz, parol xeshini yaratish uchun alohida vositadan (masalan, shu vositadan) foydalanishingiz kerak boʻladi. Keyin PASSWORDS_HASHED muhit oʻzgaruvchisini 1 ga (yoki boshqa har qanday qiymatga) belgilab, serverga xeshlangan parollarni kutishni aytishingiz mumkin.

Xeshlangan parollar ishlatilganda, SYNC_USER oʻzgaruvchilari username:password_hash formatida boʻlishi kutiladi, bunda password_hash — PHC Formatidagi parol xeshi.

Storage Location (Saqlash joyi)

Server kolleksiyangiz va mediangiz nusxasini jildda saqlashi kerak. Standart holatda bu ~/.syncserver; buni SYNC_BASE muhit oʻzgaruvchisini belgilab oʻzgartirishingiz mumkin.

  • Bu sizning oddiy Anki maʼlumotlar jildingiz bilan bir xil joy boʻlmasligi kerak, chunki server va klient alohida nusxalarni saqlashi kerak.
  • Maʼlumotlaringizni serverga sinxronlashingiz kerak, fayllarni server jildiga qoʻlda nusxalamasligingiz kerak.

Public Access (Ommaviy kirish)

Server shifrlanmagan HTTP ulanishini tinglaydi, shuning uchun uni toʻgʻridan- toʻgʻri internetga ochib qoʻyish yaxshi fikr emas. Foydalanishni mahalliy tarmogʻingiz bilan cheklashni yoki serverning oldiga qandaydir shifrlash qoʻyishni xohlaysiz, masalan VPN (Tailscale oson ekan) yoki HTTPS reverse proksi (reverse proxy).

Server bogʻlanadigan host va portni oʻzgartirish uchun SYNC_HOST va SYNC_PORT ni belgilashingiz mumkin.

Client Setup (Klientni sozlash)

Server URL (Server URL manzili)

Kompyuteringizning tarmoq IP manzilini aniqlab, har bir Anki klientingizni shu manzilga yoʻnaltirishingiz kerak, masalan http://192.168.1.200:8080/ kabi. URL ni sozlamalarda sozlash mumkin.

AnkiMobile'dan foydalansangiz va mahalliy tarmogʻingizdagi serverga ulana olmasangiz, iltimos, iOS sozlamalariga kirib, pastga yaqin joyda Anki'ni toping va "Allow Anki to access local network" (Anki'ga mahalliy tarmoqqa kirishga ruxsat berish) ni oʻchirib, keyin yana yoqing.

Eski kompyuter klientlari SYNC_ENDPOINT va SYNC_ENDPOINT_MEDIA ni belgilashingizni talab qilgan. Eski klientdan foydalansangiz, ularni mos ravishda http://192.168.1.200:8080/sync/ va http://192.168.1.200:8080/msync/ kabi kiritasiz. 2.16 dan oldingi AnkiDroid klientlari ikkala endpoint uchun alohida sozlashni talab qiladi.

Credentials (Hisob maʼlumotlari)

Sinxronlay olish uchun foydalanuvchi hisob maʼlumotlaringizni (masalan, SYNC_USER1) sozlamalardagi AnkiWeb account (AnkiWeb hisobi) boʻlimiga kiriting.

Reverse Proxies (Reverse proksilar)

HTTPS kirishini taʼminlash uchun reverse proksidan (masalan, nginx) foydalansangiz va kichik yoʻlga (subpath) bogʻlansangiz (masalan, http://example.com/custom/ -> http://localhost:8080/), Anki'ni sozlashda oxirida qiya chiziq (trailing slash) qoʻyganingizga ishonch hosil qilishingiz kerak. Oʻrniga http://example.com/custom deb yozsangiz, ishlamaydi.

Caddy'dan foydalansangiz, media fayllarni yuklab olishda ulanish muammolarining oldini olish uchun http oʻqish buferi hajmini oshiring.

reverse_proxy http://127.0.0.1:8080 {
	transport http {
		read_buffer 512k
	}
}

iOS'da TLS 1.3 qoʻllab-quvvatlanmaydi, shuning uchun reverse proksingizda TLS 1.2 yoqilgan boʻlishi kerak, aks holda "error code -9836" xatosini olasiz.

Large Requests (Katta soʻrovlar)

AnkiWeb'ning yuklash uchun standart chegarasi standart holatda qoʻllanadi. Chegarani oshirmoqchi boʻlsangiz, MAX_SYNC_PAYLOAD_MEGS ni 100 dan katta songa ixtiyoriy ravishda belgilashingiz mumkin. Shuni yodda tutingki, reverse proksidan foydalansangiz, chegarani u yerda ham oʻzgartirishingiz kerak boʻlishi mumkin.

Contributing Changes (Oʻzgarishlar kiritish)

Bu server Anki bilan birga qadoqlangani uchun, soddalik — dizayn maqsadi: u alohida/oila foydalanishiga moʻljallangan va REST API yoki tashqi maʼlumotlar bazalari kabi narsalarni qoʻshadigan PR (pull request) lar hozircha qabul qilinishi dargumon. Shubhangiz boʻlsa, PR ustida ishlashni boshlashdan oldin murojaat qiling.

Mavjud API yechimini qidirayotgan boʻlsangiz, AnkiConnect qoʻshimchasi ehtiyojlaringizga mos kelishi mumkin.
