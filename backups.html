Zaxira nusxalar

Automatic backups (Avtomatik zaxira nusxalar)

Anki karta maʼlumotlaringizning avtomatik zaxira nusxalarini yaratadi. Ularga kartalaringizdagi matn va rejalashtirish maʼlumotlaringiz kiradi, lekin tovush yoki rasm fayllari kirmaydi.

Avtomatik zaxira nusxalar xatolardan tiklanish uchun foydali boʻlishi mumkin, lekin faqat ularga tayanmaslik kerak. Ular mahalliy qurilmangizda saqlangani uchun, qurilmangiz buzilsa yoki oʻgʻirlansa, sizni himoya qilmaydi. Ularni qoʻlda yaratiladigan zaxira nusxalar bilan birga ishlatishni tavsiya qilamiz.

Restoring (Tiklash)

Avtomatik zaxira nusxadan tiklash uchun:

  • Anki'ni oching va File (Fayl) menyusidan Switch Profile (Profilni almashtirish) ni tanlang.
  • "Open Backup" (Zaxira nusxani ochish) tugmasini bosing.
  • Tiklamoqchi boʻlgan zaxira nusxani tanlang.

Zaxira nusxadan tiklaganingizda, zaxira nusxa yaratilganidan keyin qilingan barcha oʻzgarishlar yoʻqoladi.

Zaxira nusxadan tiklaganingizda Anki avtomatik sinxronlash va zaxira nusxalashni oʻchirib qoʻyadi. Toʻgʻri zaxira nusxa tiklanganiga ishonch hosil qilganingizdan keyin, odatiy holatga qaytish uchun Anki'ni yopib, qayta oching.

Creating (Yaratish)

Zaxira nusxalar muntazam yaratiladi. Zaxira nusxalar orasidagi vaqtni sozlamalar ekranida moslashingiz mumkin. Standart qiymat — 30 daqiqa.

Baʼzi amallar, sozlangan vaqt hali oʻtmagan boʻlsa ham, zaxira nusxa yaratishni ishga tushiradi:

  • Bir tomonlama sinxronlashda yuklab olish (download)
  • File > Import (Fayl > Import) orqali .colpkg faylni import qilish
  • Tools > Check Database (Asboblar > Maʼlumotlar bazasini tekshirish)

Zaxira nusxalar ikki kunlik boʻlgandan keyin Anki eskirgan baʼzilarini oʻchira boshlaydi. Nechta kunlik, haftalik va oylik zaxira nusxa saqlashni xohlashingizni sozlashingiz mumkin.

2.1.50 da yaratilgan zaxira nusxalarni Anki'ning eski versiyalariga import qilib boʻlmaydi.

Manual colpkg backups (Qoʻlda yaratiladigan colpkg zaxira nusxalar)

Restoring (Tiklash)

Qoʻlda yaratilgan zaxira nusxadan File > Import (Fayl > Import) yordamida tiklashingiz mumkin.

Creating (Yaratish)

Anki 2.1.50+ da File > Create Backup (Fayl > Zaxira nusxa yaratish) yordamida zaxira nusxani darhol yaratishingiz mumkin. Bu oddiy avtomatik zaxira nusxalar kabi ishlaydi va media fayllarni oʻz ichiga olmaydi.

Tovush va rasmlaringizni ham oʻz ichiga olgan zaxira nusxa yaratish uchun:

  • File menyusidan Export (Eksport) ni tanlang.
  • "Anki collection package (.colpkg)" tanlanganiga ishonch hosil qiling.
  • "include media" (mediani kiritish) variantini yoqing.

Bu barcha kartalaringiz va ular ishlatadigan har qanday tovush/rasmlarni oʻz ichiga olgan .colpkg fayl yaratadi. Faylni xavfsiz joyda, masalan boshqa qurilmada yoki Dropbox yoki Google Drive kabi bulutli fayl saqlash xizmatida saqlashni tavsiya qilamiz.

AnkiWeb

Kolleksiyangizni AnkiWeb bilan sinxronlash qurilmangiz yoʻqolishi yoki oʻgʻirlanishidan maʼlum darajada himoya qiladi. Kolleksiyangizni AnkiWeb'dan tiklashingiz kerak boʻlsa, sozlamalar ekranida bir tomonlama sinxronlashni majburlashingiz yoki yangi qurilmadan sinxronlab, keyin "Download" (Yuklab olish) ni tanlashingiz mumkin.

Deletion log (Oʻchirish jurnali)

Anki oʻchirilgan yozuvlarni profil jildingizdagi deleted.txt nomli matnli faylga yozib boradi. Bu yozuvlar File > Import (Fayl > Import) oʻqiy oladigan matn formatida. Tarixan Anki bir vaqtning oʻzida faqat bitta yozuv turini qoʻllab-quvvatlagan. Shuning uchun turli yozuv turlaridan yozuvlarni oʻchirgan boʻlsangiz, avval faylni har bir yozuv turi uchun alohida fayllarga ajratishingiz kerak edi.

Biroq Anki 25.09.2 dan yangi versiyalarda yaratilgan profillarning deleted.txt faylining tepasida quyidagi parcha bor (shuning uchun deleted.txt ni faylni ajratmasdan import qilish mumkin):

#guid column:1
#notetype column:2

deleted.txt har bir profil uchun noyob va turli foydalanuvchi profillari oʻrtasida almashtirib boʻlmaydi.
