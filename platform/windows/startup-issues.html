Kompyuter qoʻllanmasi

Windows'da ishga tushirish muammolari

Xato yoʻq, lekin ilova koʻrinmaydi

Anki'ni ishga tushirganingizda hech qanday xato xabarisiz u ekranda paydo boʻlmasa, quyidagilarni sinab koʻrishingiz mumkin:

  • Qoʻshimcha va tashqi monitorlarni uzib qoʻying.
  • Anki'ning eng yangi versiyasini oʻrnating.
  • Agar kasr ajratuvchi belgi (decimal separator) nuqta boʻlmasa, uni sozlang.
  • Anki'ning eski 2.1.35-alternate versiyasini oʻrnating.

Windows yangilanishlari

Anki'ni ishga tushirganingizda quyidagiga oʻxshash xabar chiqishi mumkin:

  • Error loading Python DLL
  • The program can't start because api-ms-win.... is missing
  • Failed to execute script runanki
  • Failed to execute script pyi_rth_multiprocessing
  • Failed to execute script pyi_rth_win32comgenpy

Bu xatolar odatda kompyuteringizda Windows yangilanishi yoki Windows kutubxonasi yoʻqligi sababli chiqadi.

Windows Update (Windows yangilanishlari) boʻlimini ochib, tizimingizda barcha yangilanishlar oʻrnatilganiga ishonch hosil qiling. Biror yangilanish oʻrnatilgan boʻlsa, oʻrnatilgach qurilmangizni qayta ishga tushiring.

Windows 7/8

Windows 7/8 da qoʻshimcha yangilanishlarni qoʻlda oʻrnatish kerak boʻlishi mumkin. Quyidagilarni sinab koʻring:

  • https://www.microsoft.com/en-us/download/details.aspx?id=48234
  • https://aka.ms/vs/15/release/vc_redist.x64.exe
  • http://www.catalog.update.microsoft.com/Search.aspx?q=kb4474419
  • http://www.catalog.update.microsoft.com/Search.aspx?q=kb4490628

Video drayver muammolari

Koʻrinish (ekran) muammolari sahifasiga qarang.

Bir nechta monitor

Agar LoadLibrary failed with error 126 xatosi chiqsa, buning sababi Anki qurilgan vositalar toʻplami (toolkit) bir nechta monitor bilan ishlashda qiynalishi boʻlishi mumkin.

Antivirus/xavfsizlik devori (firewall) dasturlari

Kompyuteringizdagi uchinchi tomon dasturlari Anki'ning ishga tushishiga toʻsqinlik qilishi mumkin. Anki uchun istisno (exception) qoʻshib koʻring yoki yordam beradimi-yoʻqmi, tekshirish uchun antivirus/xavfsizlik devorini vaqtincha oʻchirib qoʻying.

Administrator huquqi

Ayrim foydalanuvchilar Anki belgisini sichqonchaning oʻng tugmasi bilan bosib, "Run as administrator" (Administrator sifatida ishga tushirish) ni tanlamaguncha Anki ishlamaganini xabar qilgan. Anki barcha maʼlumotlarini foydalanuvchi papkangizda saqlaydi va administrator huquqini talab qilmasligi kerak, lekin boshqa usullar ish bermasa, buni ham sinab koʻrishingiz mumkin.

Yangilangandan keyin bir nechta Anki nusxasi qolib ketishi

Yangilash jarayoni natijasida kompyuteringizda bir nechta Anki oʻrnatilgan boʻlib qolsa (masalan, C:\Program Files\Anki va C:\Program Files (x86)\Anki ichida), ular ishlamaydigan holatda qolishi va Anki hech qanday xato xabarisiz ishga tushmasligi mumkin.

Kompyuteringizdagi Anki'ning barcha nusxalarini oʻchirib tashlab koʻring. Buning uchun Windows Settings > Apps & features (yoki Apps > Installed apps) boʻlimidan ularni topib oʻchiring yoki har bir Anki dastur papkasidagi uninstall.exe ni ishga tushiring. Shundan keyin Anki'ni qaytadan oʻrnating.

Xatolarni aniqlash (debugging)

Anki'ni terminaldan ishga tushirish ayrim xatolar haqida bir oz koʻproq maʼlumot berishi mumkin. Anki'ning eng yangi versiyasini oʻrnatib, barcha Windows yangilanishlari oʻrnatilganiga ishonch hosil qilgach, Anki'ni toʻgʻridan-toʻgʻri ishga tushirish oʻrniga Windows tugmasini bosing (yoki Start menyusini oching), cmd deb yozing va Command Prompt (buyruq qatori) ni ishga tushiring. Terminal oynasi ochilgach, quyidagi buyruqni qoʻyib (paste), Enter tugmasini bosing. (Anki standart boʻlmagan joyga oʻrnatilgan boʻlsa, yoʻl boshqacha boʻladi.)

%LocalAppData%\Programs\Anki\anki-console.bat

Anki 25.07 dan 25.09.4 gacha boʻlgan versiyalari uchun quyidagini qoʻying:

%LocalAppData%\Programs\Anki\anki-console.exe

Ehtimol, Anki avvalgidek ochilmaydi, lekin terminal oynasidagi chiqish muammo sababi haqida nimadir koʻrsatishi mumkin.

Boshqa hech narsa yordam bermasa

Yuqoridagi yechimlarni sinab koʻrgach ham Anki'ni ishga tushira olmasangiz, sizda ikkita variant qoladi:

  • Python orqali ishga tushirib koʻrishingiz mumkin.
  • Eski vositalar toʻplami (toolkit) bilan qurilgan Anki'ning eski versiyasini, masalan, 2.1.35-alternate yoki 2.1.15 ni sinab koʻrishingiz mumkin.
