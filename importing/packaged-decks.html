Paketlangan toʻplamlar

Anki paketlari (.apkg fayllar) boshqa foydalanuvchilarning toʻplamlari, yozuvlari, yozuv turlari va kartalarini import qilish imkonini beradi. Ular odatda AnkiWeb orqali ulashiladi.

Scheduling (Rejalashtirish)

Anki paketlarida rejalashtirish maʼlumotlari ham boʻlishi mumkin, bu toʻplamlarni qurilmalar yoki profillar oʻrtasida koʻchirmoqchi boʻlsangiz foydali. Biroq boshqa birov ulashgan toʻplamni import qilayotganda, odatda uning karta intervallari yoki takrorlash tarixini qabul qilishni xohlamaysiz.

Import qilingan kartalarda kutilmagan darajada katta intervallarni uchratsangiz, toʻplam muallifi oʻzining rejalashtirish maʼlumotlarini tasodifan kiritib yuborgan boʻlishi mumkin. Import qilingan kartalarni qayta tiklash uchun Set Due Date funksiyasidan foydalanishingiz mumkin. Anki 23.10 va undan yangi versiyalarda import jarayonida "Import any learning progress" (Har qanday oʻrganish jarayonini import qilish) variantini tanlamasdan qoldirib, har qanday rejalashtirish maʼlumotini olib tashlashingiz mumkin. Bu import qilingan kartalardan "leech" yoki "marked" teglarini ham olib tashlaydi.

Updating (Yangilash)

.apkg faylni import qilganingizda, Anki undagi yozuvlardan oldingi import sababli kolleksiyangizda allaqachon bor boʻlganlarini aniqlaydi. Fayldagi yozuvlar sizdagi nusxadan yangiroq boʻlsa, yozuvlar standart holatda fayl mazmuni bilan yangilanadi.

Bu yangilash jarayoni, yozuv turi oʻzgargan boʻlsa (masalan, siz yoki toʻplam muallifi yozuv turiga qoʻshimcha maydon qoʻshganingizda), odatda mumkin emas. Fayldagi yetishmayotgan yozuvlarni baribir import qila olasiz, lekin avval import qilgan yozuvlaringiz, toʻplam muallifi oʻzgartirishlar kiritgan boʻlsa ham, yangilanmaydi.

Anki 23.10 and Later (Anki 23.10 va undan keyingi versiyalar)

Anki 23.10 koʻproq moslashuvchanlikni joriy qildi: yozuvlar va yozuv turlarini shartsiz yangilashni, oʻzgartirishlaringizni har doim ustidan yozishni tanlashingiz mumkin yoki, aksincha, mavjud obyektlarni hech qachon yangilamaslikni.

Shuningdek, siz ham, toʻplam muallifi ham bir yozuv turini oʻzgartirgan boʻlsangiz, endi ikki versiyani birlashtirishni (merge) tanlashingiz mumkin. Bu ikkalasida ham mavjud boʻlgan barcha shablonlar va maydonlarni saqlab qoladi, lekin toʻliq sinxronlashni talab qiladi va boshqa mavjud yozuvlarni oʻzgartirilgan deb belgilashi mumkin.

Note to Deck Authors (Toʻplam mualliflariga eslatma)

Birlashtirish Anki 2.1.67 da joriy qilingan shablon va maydon ID'lariga tayanadi. Shablon yoki maydonda ID boʻlmasa, chunki u oldingi versiyada yaratilgan boʻlsa, Anki nomlarni solishtirib, unga mos keladiganini topishga harakat qiladi.

Yozuv turlarini maydon va shablon ID'lari bilan ulashishning nega foydali ekanligi hamda ularni mavjudlariga qanday qoʻshish haqida shu qoʻshimchaga qarang.
