Matnli fayllar

Maydonlari vergul, nuqtali vergul yoki tabulyatsiya (tab) bilan ajratilgan har qanday oddiy matnli faylni, ayrim shartlar bajarilsa, Anki'ga import qilish mumkin.

  • Fayllar oddiy matn formatida boʻlishi kerak (myfile.txt). myfile.xls, myfile.rtf, myfile.doc kabi boshqa formatlarni avval oddiy matnli fayl sifatida saqlash kerak.

  • Fayllar UTF-8 formatida boʻlishi kerak (quyidagi boʻlimga qarang).

  • Anki fayldagi maydonlar sonini birinchi (izoh boʻlmagan) qatorga qarab aniqlaydi. Fayldagi keyingi yozuvlarning baʼzilarida maydonlar kamroq boʻlsa, Anki yetishmayotgan maydonlarni boʻsh deb hisoblaydi. Baʼzi yozuvlarda ortiqcha maydonlar boʻlsa, ortiqcha mazmun import qilinmaydi.

  • Anki faylingiz qaysi maydon ajratuvchisidan (vergul, tab va hokazo) foydalanayotganini taxmin qilishga harakat qiladi. Notoʻgʻri taxmin qilsa, uni import sozlamalari oynasida oʻzgartirib, natijani oldindan koʻrishingiz mumkin. Yoki muayyan maydon ajratuvchisini majburlash uchun fayl sarlavhalari qoʻshishingiz mumkin.

Matnli faylingizdagi maydonlarni yozuvlaringizdagi istalgan maydonga, jumladan teglar maydoniga ham moslashtirish mumkin. Import qilishda matnli fayldagi qaysi maydon yozuvdagi qaysi maydonga toʻgʻri kelishini tanlashingiz mumkin.

Matnli faylni import qilganingizda, kartalarni qaysi toʻplamga joylashni tanlashingiz mumkin. Shuni yodda tutingki, shablonlaringizdan bir yoki bir nechtasi uchun toʻplamni almashtirish (deck override) sozlamasi oʻrnatilgan boʻlsa, kartalar siz tanlagan toʻplamga emas, oʻsha toʻplamga tushadi.

Mana uchta maydonli yaroqli fayl namunasi:

    apple;banana;grape
    first field;second field;third field

Maydonlarga yangi qator yoki maydon ajratuvchisini kiritishning ikki usuli bor.

Belgilarni ekranlash — maydon mazmunini qoʻsh tirnoq ichiga olish:

    hello;"this is
    a two line answer"
    two;this is a one line field
    "this includes a ; (semicolon)";another field

Maydon qayerdan boshlanib, qayerda tugashini belgilash uchun tirnoqlar ishlatilgani sababli, ularni maydoningiz ichiga kiritmoqchi boʻlsangiz, ularni oddiy ishlov berishdan "ekranlash" (escape) uchun har bir qoʻsh tirnoqni ikkita qoʻsh tirnoq bilan almashtirishingiz kerak, mana bunday:

    field one;"field two with ""escaped quotes"" inside it"

CSV faylni yaratish uchun Libreoffice kabi jadval dasturidan foydalansangiz, u qoʻsh tirnoqlarni ekranlashni avtomatik bajaradi.

HTML yangi qatorlaridan foydalanish:

    hello; this is<br>a two line answer
    two; this is a one line one

HTML yangi qatorlari ishlashi uchun import oynasida Allow HTML in fields (Maydonlarda HTML'ga ruxsat berish) ni yoqishingiz kerak.

Ekranlangan koʻp qatorli matnlar bir necha qatorga yoyilgan cloze deletion'lardan foydalansangiz, toʻgʻri ishlamaydi. Bunday holda oʻrniga HTML yangi qatorlaridan foydalaning.

Teglarni ham boshqa maydonga kiritib, import oynasida uni teglar maydoni sifatida tanlashingiz mumkin:

    first field;second field;tags

Mana birinchi qatori eʼtiborsiz qoldiriladigan (#) yaroqli fayl namunasi:

    # this is a comment and is ignored
    foo bar;bar baz;baz quux
    field1;field2;field3

Spreadsheets and UTF-8 (Jadval dasturlari va UTF-8)

Faylingizda lotin boʻlmagan belgilar (urgʻu belgilari, yapon belgilari va hokazo) boʻlsa, Anki fayllar "UTF-8 kodlash"da saqlanishini kutadi. Buning eng oson yoʻli — faylingizni tahrirlash uchun Excel oʻrniga bepul LibreOffice jadval dasturidan foydalanish, chunki u UTF-8 ni oson qoʻllab-quvvatlaydi va Excel'dan farqli oʻlaroq koʻp qatorli mazmunni ham toʻgʻri eksport qiladi. Excel'dan foydalanishda davom etmoqchi boʻlsangiz, qoʻshimcha maʼlumot uchun shu hujjatga qarang.

Jadvalingizni LibreOffice orqali Anki oʻqiy oladigan faylga saqlash uchun File > Save As (Fayl > Boshqa nom bilan saqlash) ga oʻting, keyin fayl turi sifatida CSV ni tanlang. Standart sozlamalarni qabul qilganingizdan keyin LibreOffice faylni saqlaydi va siz saqlangan faylni Anki'ga import qilishingiz mumkin.

HTML

Anki matnli fayllardan import qilingan matnni HTML (veb-sahifalar uchun ishlatiladigan til) sifatida qabul qilishi mumkin. Bu qalin, kursiv va boshqa formatlashga ega matnni matnli faylga eksport qilib, qayta import qilish mumkinligini bildiradi. HTML formatlashni kiritmoqchi boʻlsangiz, import qilishda "allow HTML in fields" (maydonlarda HTML'ga ruxsat berish) katakchasini belgilashingiz mumkin. Mazmunida burchakli qavslar yoki boshqa HTML sintaksisi boʻlgan kartalarni import qilmoqchi boʻlsangiz, buni oʻchirib qoʻyishingiz mumkin.

Faylingizni formatlash uchun HTML'dan foydalanmoqchi boʻlsangiz-u, burchakli qavslar yoki ampersandlarni ham kiritmoqchi boʻlsangiz, quyidagi almashtirishlardan foydalanishingiz mumkin:

Belgi Almashtirish
< &lt;
> &gt;
& &amp;

Importing Media (Media import qilish)

Matnli fayl importidan audio va rasmlarni kiritmoqchi boʻlsangiz, fayllarni collection.media jildiga nusxalang. Media jildiga ichki jildlar qoʻymang, aks holda baʼzi funksiyalar ishlamaydi.

Fayllarni nusxalaganingizdan keyin, matnli faylingizdagi maydonlardan birini quyidagicha oʻzgartiring.

    <img src="myimage.jpg">

yoki

    [sound:myaudio.mp3]

Yoki Browse oynasidagi topish va almashtirish funksiyasidan foydalanib, barcha maydonlarni birdaniga yangilashingiz mumkin. Har bir maydonda "myaudio" kabi matn boʻlsa va uni tovush chalishga aylantirmoqchi boʻlsangiz, regular expressions (muntazam ifodalar) varianti yoqilgan holda (.*) ni qidirib, "[sound:\1.mp3]" bilan almashtirasiz.

Bunday havolalar bor matnli faylni import qilayotganda "Allow HTML" (HTML'ga ruxsat berish) variantini yoqishingiz shart.

Buni shablonda qilish xayolingizga kelishi mumkin, masalan:

    <img src="{{field name}}">

Anki buni ikki sababga koʻra qoʻllab-quvvatlamaydi: ishlatilgan mediani qidirish qimmatga tushadi, chunki har bir karta chizilishi (render) kerak, bunday funksiya ulashilgan toʻplamlardan foydalanuvchilar uchun ham aniq emas. Iltimos, oʻrniga "topish va almashtirish" usulidan foydalaning.

Bulk Media (Koʻp miqdordagi media)

Katta hajmdagi mediani birdaniga import qilishning yana bir usuli — media import qoʻshimchasidan foydalanish. Bu qoʻshimcha siz tanlagan jilddagi barcha fayllar uchun avtomatik yozuvlar yaratadi: fayl nomlari old tomonda (fayl kengaytmasisiz, masalan apple.jpg fayli boʻlsa, old tomonda "apple" yoziladi), rasmlar yoki audio esa orqa tomonda boʻladi. Media va fayl nomlarining boshqacha joylashuvini xohlasangiz, keyin yaratilgan kartalarning yozuv turini oʻzgartirishingiz mumkin.

Duplicates and Updating (Dublikatlar va yangilash)

Matnli fayllarni import qilishda Anki yozuv noyob ekanini aniqlash uchun birinchi maydondan foydalanadi. Standart holatda, import qilinayotgan faylning birinchi maydoni kolleksiyangizdagi mavjud yozuvlardan biriga mos kelsa va mavjud yozuv import qilinayotgan tur bilan bir xil turda boʻlsa, mavjud yozuvning boshqa maydonlari import qilinayotgan fayl mazmuniga qarab yangilanadi. Import ekranidagi ochiladigan roʻyxat bu xulqni oʻzgartirish imkonini beradi: dublikatlarni butunlay eʼtiborsiz qoldirish yoki mavjudlarini yangilash oʻrniga ularni yangi yozuv sifatida import qilish.

Match scope (Moslik doirasi) sozlamasi dublikatlar qanday aniqlanishini boshqaradi. Note type (Yozuv turi) tanlanganda, Anki bir xil yozuv turidagi boshqa yozuvning birinchi maydoni xuddi shunday boʻlsa, dublikat deb aniqlaydi. Note type and deck (Yozuv turi va toʻplam) ga qoʻyilganda, mavjud yozuv siz import qilayotgan toʻplamda ham boʻlsagina dublikat deb belgilanadi.

Yangilash yoqilgan boʻlsa va import qilayotgan yozuvlaringizning eski versiyalari kolleksiyangizda allaqachon bor boʻlsa, ular import oynasida siz belgilagan toʻplamga koʻchirilmasdan, joyida (hozirgi toʻplamlarida) yangilanadi. Yozuvlar joyida yangilansa, ularning barcha kartalaridagi mavjud rejalashtirish maʼlumotlari saqlanadi.

.apkg fayllarida dublikatlar qanday qayta ishlanishi haqida maʼlumot olish uchun Toʻplam paketlari boʻlimiga qarang.

File Headers (Fayl sarlavhalari)

Anki 2.1.54+ matnli faylga kiritilishi mumkin boʻlgan baʼzi sarlavhalarni qoʻllab-quvvatlaydi, ular importni kuchliroq yoki qulayroq qiladi. Ular #key:value (#kalit:qiymat) juftliklaridan iborat va fayl tepasida alohida qatorlarda boʻlishi kerak.

Kalit (Key) Ruxsat etilgan qiymatlar Xulqi
separator Comma, Semicolon, Tab, Space, Pipe, Colon yoki mos literal belgilar Maydon ajratuvchisini belgilaydi.
html true, false Fayl HTML sifatida qabul qilinishini belgilaydi.
tags Boʻsh joy bilan ajratilgan teglar roʻyxati Roʻyxatdagi teglarni har bir import qilingan yozuvga qoʻshadi.
columns Oldin belgilangan ajratuvchi bilan ajratilgan nomlar roʻyxati Ustunlar sonini belgilaydi va import qilishda ularning berilgan nomlarini koʻrsatadi.
notetype Yozuv turi nomi yoki identifikatori Yozuv turi mavjud boʻlsa, uni oldindan tanlab qoʻyadi.
deck Toʻplam nomi yoki identifikatori Toʻplam mavjud boʻlsa, uni oldindan tanlab qoʻyadi.
notetype column 1, 2, 3, ... Qaysi ustunda har bir yozuvning yozuv turi nomi yoki identifikatori borligini belgilaydi, Notetype Column ga qarang.
deck column 1, 2, 3, ... Qaysi ustunda har bir yozuvning toʻplam nomi yoki identifikatori borligini belgilaydi, Deck Column ga qarang.
tags column 1, 2, 3, ... Qaysi ustunda har bir yozuvning teglari borligini belgilaydi.
guid column 1, 2, 3, ... Qaysi ustunda har bir yozuvning GUID'i borligini belgilaydi, GUID Column ga qarang.

Baʼzi sarlavhalarning qoʻshimcha oqibatlari bor.

Notetype Column (Yozuv turi ustuni)

Odatda fayldagi barcha yozuvlar bitta yozuv turiga moslashtiriladi. Yozuv turi nomlari yoki identifikatorlari boʻlgan ustun mavjud boʻlsa, bu oʻzgaradi.

Bu turli yozuv turidagi yozuvlarni import qilish imkonini beradi, ularning maydonlari esa bilvosita moslashtiriladi: birinchi oddiy ustun yozuv turidan qatʼi nazar har qanday yozuvning birinchi maydoni uchun, ikkinchi oddiy ustun ikkinchi maydon uchun ishlatiladi va hokazo. Bu yerda oddiy ustun — toʻplamlar, teglar, yozuv turlari yoki GUID'lar kabi maxsus maʼlumot bermaydigan ustun.

Deck Column (Toʻplam ustuni)

Odatda matnli faylni import qilish natijasida yaratilgan har qanday yangi kartalar siz tanlagan bitta toʻplamga joylashtiriladi. Biroq fayl toʻplam ustunini oʻz ichiga olsa, yozuvning yangi kartalari oʻrniga uning koʻrsatilgan toʻplamiga joylashtiriladi. Toʻplam mavjud boʻlmasa, berilgan nomli toʻplam yaratiladi.

GUID Column (GUID ustuni)

GUID — Globally Unique Identifier (Global noyob identifikator) degani. Anki'da yozuv yaratganingizda, Anki har bir yozuvga dublikatni tekshirish uchun ishlatilishi mumkin boʻlgan noyob ID beradi. Yozuvlaringizni GUID bilan birga eksport qilsangiz, yozuvlarga oʻzgartirish kiritishingiz mumkin va GUID maydonini oʻzgartirmaguningizcha, yozuvlarni qayta import qilib, mavjud yozuvlarni yangilashingiz mumkin.

Shuni yodda tutingki, GUID'ni Anki yaratishi moʻljallangan. MYNOTE0001 kabi oʻz ID'laringizni yaratayotgan boʻlsangiz, ularni Anki'ning ichki GUID'iga berish oʻrniga birinchi maydonga qoʻyish tavsiya etiladi. Import qilishda Anki dublikatni tekshirish uchun birinchi maydondan ham, GUID'dan ham foydalana oladi, shuning uchun yozuvlaringizni yangilay olish uchun ID'larni GUID qilish shart emas.

Yana bir muhim narsa: dublikat varianti GUID'i boʻsh boʻlmagan qatorlar uchun ishlamaydi. GUID berilgan boʻlsa va u kolleksiyada allaqachon mavjud boʻlsa, dublikat yaratilmaydi.
