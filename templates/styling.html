Bezak va HTML

Kartalarni bezash

YouTube'da kartalarni bezash haqida video koʻrishingiz mumkin. Videoda Anki 2.0 interfeysi koʻrsatilgan, lekin tushunchalar asosan bir xil.

Kartalar (Cards) oynasidagi bezak (styling) boʻlimiga "Back Template" (Orqa tomon shabloni) tugmasi yonidagi "Styling" (Bezak) tugmasini bosib kirish mumkin. Bu boʻlimda kartaning fon rangini, standart shriftni, matn tekislanishini va hokazolarni oʻzgartirishingiz mumkin.

Sizga mavjud standart opsiyalar:

font-family
Kartada ishlatiladigan shrift nomi. Shrift nomida "MS Unicode" kabi probel boʻlsa, shrift nomini qoʻshtirnoq ichiga olishingiz kerak, mana bunday: font-family: "MS Unicode";. Bitta kartada bir nechta shriftdan foydalanish ham mumkin; bu haqida quyida maʼlumot bor.

font-size
Shrift oʻlchami pikselda. Oʻzgartirayotganda oxirida px qolishiga ishonch hosil qiling.

text-align
Matn markazga, chapga yoki oʻngga tekislanishi.

color
Matn rangi. "blue", "lightyellow" kabi oddiy rang nomlari ishlaydi yoki istalgan rangni tanlash uchun HTML rang kodlaridan foydalanishingiz mumkin. Batafsil maʼlumot uchun ushbu veb-sahifaga qarang.

background-color
Karta fonining rangi.

Bezak boʻlimiga istalgan CSS'ni joylashtirish mumkin: ilgʻor foydalanuvchilar, masalan, fon rasmi yoki gradient qoʻshish kabi ishlarni qilishni xohlashi mumkin. Maʼlum bir formatlashni qanday qilishni bilmasangiz, buni CSS'da qanday qilish haqida internetdan qidiring, chunki bu borada juda koʻp hujjatlar mavjud.

Bezak barcha kartalar uchun umumiy, yaʼni oʻzgartirish kiritsangiz, u shu yozuv turining barcha kartalariga taʼsir qiladi. Biroq muayyan kartaga xos bezak belgilash ham mumkin. Quyidagi misol birinchisidan tashqari barcha kartalarda sariq fondan foydalanadi:

.card {
    background-color: yellow;
}
.card1 {
    background-color: blue;
}

Rasm oʻlchamini oʻzgartirish

Anki standart holatda rasmlarni ekranga sigʻdirish uchun kichraytiradi. Buni bezak boʻlimingizning pastiga (standart .card { ... } dan tashqariga) quyidagini qoʻshib oʻzgartirishingiz mumkin:

img {
    max-width: none;
    max-height: none;
}

AnkiDroid ba'zan rasmlarni ekranga sigʻdirib oʻlchamini oʻzgartirishda muammoga duch keladi. CSS yordamida rasmning maksimal oʻlchamini belgilash buni tuzatishi kerak, lekin AnkiDroid 2.9 dan boshlab bu eʼtiborsiz qoldirilayotganga oʻxshaydi. Yechim: har bir uslub direktivasiga !important qoʻshing, masalan:

img {
    max-width: 300px !important;
    max-height: 300px !important;
}

Rasmlar uslubini oʻzgartirganingizda belgilangan kartalarda koʻrinadigan yulduzcha ham oʻzgarib ketganini (masalan, haddan tashqari katta boʻlib qolganini) koʻrsangiz, uni quyidagi bilan alohida belgilashingiz mumkin:

img#star {
  ...;
}

Kartalarning bezagini Chrome yordamida interaktiv ravishda oʻrganishingiz mumkin:

webview oʻzgarishlari

Anki 2.1.50 va undan yangi versiyalar tahrirlagich ichida rasm oʻlchamini oʻzgartirishni oʻzida qoʻllab-quvvatlaydi.

Maydonlarni bezash

Standart bezak butun kartaga qoʻllanadi. Muayyan maydonlar yoki kartaning bir qismi uchun boshqa shrift, rang va hokazolarni ham belgilashingiz mumkin. Bu chet tillarini oʻrganishda ayniqsa muhim, chunki mos shrift tanlanmagan boʻlsa, Anki baʼzan belgilarni toʻgʻri koʻrsata olmaydi.

Aytaylik, sizda "Expression" maydoni bor va unga macOS'ning tay shrifti "Ayuthaya" ni bermoqchisiz. Shabloningiz allaqachon quyidagicha deb faraz qiling:

    What is {{Expression}}?

    {{Notes}}

Biz bezamoqchi boʻlgan matnni biror HTML ichiga olishimiz kerak. Matn oldiga quyidagini qoʻyamiz:

    <div class=mystyle1>

Va matn orqasiga quyidagini:

    </div>

Matnni yuqoridagidek oʻrab, biz Anki'ga oʻralgan matnni keyinroq yaratadigan "mystyle1" nomli maxsus uslub bilan bezashni aytamiz.

Shunday qilib, butun "What is …​?" iborasi tay shriftidan foydalanishini xohlasak, quyidagidan foydalanamiz:

    <div class=mystyle1>What is {{Expression}}?</div>

    {{Notes}}

Faqat ibora maydonining oʻzi tay shriftidan foydalanishini xohlasak, esa:

    What is <div class=mystyle1>{{Expression}}</div>?

    {{Notes}}

Shablonni tahrirlagach, endi shablonlar orasidagi Styling (Bezak) boʻlimiga oʻtishimiz kerak. Tahrirlashdan oldin u taxminan quyidagicha koʻrinadi:

.card {
    font-family: arial;
    font-size: 20px;
    text-align: center;
    color: black;
    background-color: white;
}

Yangi uslubingizni pastiga qoʻshing, shunda u quyidagicha koʻrinadi:

.card {
    font-family: arial;
    font-size: 20px;
    text-align: center;
    color: black;
    background-color: white;
}

.mystyle1 {
    font-family: ayuthaya;
}

Uslubga xohlagan bezakni kiritishingiz mumkin. Shrift oʻlchamini ham kattalashtirmoqchi boʻlsangiz, mystyle1 boʻlimini quyidagicha oʻzgartirasiz:

.mystyle1 {
    font-family: ayuthaya;
    font-size: 30px;
}

Shuningdek, maxsus shriftlarni toʻplamingiz bilan birga joylash ham mumkin, shunda ularni kompyuteringiz yoki mobil qurilmangizga oʻrnatish shart emas. Batafsil maʼlumot uchun shriftlarni oʻrnatish boʻlimiga qarang.

Audioni qayta ijro etish tugmalari

Kartalaringizda audio yoki matnni ovozga aylantirish (TTS) boʻlsa, Anki audioni qayta ijro etish uchun bosish mumkin boʻlgan tugmalarni koʻrsatadi.

Tugmalarni koʻrmaslikni yoqtirsangiz, ularni sozlamalar oynasida yashirishingiz mumkin.

Ularning koʻrinishini karta bezagida sozlashingiz mumkin, masalan, ularni kichikroq va rangli qilish uchun quyidagidan foydalanishingiz mumkin:

.replay-button svg {
    width: 20px;
    height: 20px;
}
.replay-button svg circle {
    fill: blue;
}
.replay-button svg path {
    stroke: white;
    fill: green;
}

Matn yoʻnalishi

Arab yoki ivrit kabi oʻngdan chapga yoziladigan tildan foydalansangiz, takrorlash paytida toʻgʻri koʻrsatilishi uchun .card boʻlimiga CSS direction xususiyatini qoʻshishingiz mumkin:

.card {
    direction: rtl;
}

Bu butun kartaning yoʻnalishini oʻzgartiradi. Faqat baʼzi maydonlarning yoʻnalishini ularga havolalarni HTML ichiga olib oʻzgartirishingiz mumkin:

    <div dir="rtl">{{Front}}</div>

Tahrirlagichda maydonlar yoʻnalishini oʻzgartirish uchun tahrirlash boʻlimiga qarang.

Kod parchalarini koʻrsatish

Anki kartalaringizga kod kiritmoqchi boʻlsangiz, matnni kod sifatida formatlash uchun HTML teglaridan foydalanishingiz mumkin. Buning uchun HTML koʻrinishini ochishingiz kerak.

Qator ichidagi kod

Matningizni <code> tegi bilan oʻrang:

<code>console.log("Hello World!");</code>

Kod bloklari

Koʻp qatorli kod uchun <pre><code> dan foydalaning:

<pre><code>
function square(number) {
  return number * number;
};
</code></pre>

Boshqa HTML

Shablonlaringizda istalgan HTML boʻlishi mumkin, yaʼni internet veb-sahifalarida ishlatiladigan barcha joylashtirish imkoniyatlaridan kartalaringizda ham foydalanish mumkin. Jadvallar, roʻyxatlar, rasmlar, tashqi sahifalarga havolalar va shunga oʻxshash narsalarning hammasi qoʻllab-quvvatlanadi. Masalan, jadvallar yordamida kartaning old va orqa tomonini yuqori va pastda emas, chap va oʻng tomonda koʻrsatadigan qilib joylashtirishni oʻzgartirishingiz mumkin.

HTML'ning barcha imkoniyatlarini yoritish ushbu qoʻllanma doirasidan tashqarida, lekin koʻproq oʻrganmoqchi boʻlsangiz, internetda HTML boʻyicha yaxshi kirish qoʻllanmalari koʻp.

Browse oynasidagi koʻrinish

Karta shablonlaringiz murakkab boʻlsa, kartalar roʻyxatidagi savol va javob ustunlarini ("Front" va "Back" deb ataladi) oʻqish qiyin boʻlishi mumkin. "Browser appearance" (Browse oynasidagi koʻrinish) opsiyasi faqat Browse oynasida ishlatiladigan maxsus shablon belgilash imkonini beradi, shunda unga faqat muhim maydonlarni kiritib, xohlasangiz, tartibini oʻzgartirishingiz mumkin. Sintaksis oddiy karta shablonlaridagi bilan bir xil.

Bu opsiyadan foydalanganda, savol ustunidagi matn javob ustuni boshida takrorlansa, Anki matnni faqat savol ustunida koʻrsatadi. Masalan, savol ustunidagi matn "People in Ladakh speak", javob esa "People in Ladakh speak Ladakhi" boʻlsa, javob ustuni faqat "Ladakhi" ni koʻrsatadi, qolganini tushirib qoldiradi.

Platformaga xos CSS

Anki turli platformalar uchun turli bezak belgilash imkonini beradigan baʼzi maxsus CSS sinflarini belgilaydi. Quyidagi misol qayerda takrorlayotganingizga qarab shriftni qanday oʻzgartirishni koʻrsatadi:

/* Windows */
.win .example {
    font-family: "Example1";
}
/* macOS */
.mac .example {
    font-family: "Example2";
}
/* Linux desktops */
.linux:not(.android) .example {
    font-family: "Example3";
}
/* both Linux desktops, and Android devices */
.linux .example {
    font-family: "Example4";
}
/* both Android and iOS */
.mobile .example {
    font-family: "Example5";
}
/* iOS */
.iphone .example,
.ipad .example {
    font-family: "Example6";
}
/* Android */
.android .example {
    font-family: "Example7";
}

Shablonda esa:

<div class="example">{{Field}}</div>

AnkiWeb'dan foydalanganda muayyan brauzerlarni tanlash uchun .gecko, .opera va .ie kabi xususiyatlardan ham foydalanishingiz mumkin. Barcha opsiyalar roʻyxati uchun http://rafael.adm.br/css_browser_selector/ saytiga qarang.

Shriftlarni oʻrnatish

Shriftlarni toʻgʻridan-toʻgʻri Anki'ga oʻrnatishingiz mumkin. Bu Anki'dan yangi shrift oʻrnatishga ruxsatingiz boʻlmagan ish yoki oʻquv kompyuterida foydalanayotganda yoki mobil qurilmada foydalanayotganda foydali.

Anki eng keng tarqalgan shrift formatlarini, masalan, TrueType (.ttf), OpenType (.otf), Web Open Font Format (.woff) va boshqalarni qoʻllab-quvvatlaydi.

Shriftni media papkasiga qoʻshish

Qoʻllab-quvvatlanadigan shriftni, masalan, "Arial.ttf" ni yuklab olgach, uni media papkasiga qoʻshishingiz kerak.

  1. Faylning nomini boshiga pastki chiziq qoʻshib oʻzgartiring, shunda u "_arial.ttf" kabi boʻladi. Pastki chiziq qoʻshish Anki'ga bu fayl shablonda ishlatilishini va ishlatilmagan mediani tekshirishda oʻchirilmasligi kerakligini bildiradi.

  2. Kompyuteringizning fayl brauzerida Anki dastur maʼlumotlari papkasiga (Fayl joylashuvlari boʻlimida batafsil), keyin esa profil papkangizga (masalan, "User 1") kiring.

  3. Papka ichida collection.media nomli papkani koʻrasiz. Nomi oʻzgartirilgan faylni shu papkaga sudrab tashlang.

Shriftdan foydalanish uchun shablonni yangilash

Shrift media papkasiga qoʻshilgandan keyin shablonni yangilashingiz kerak.

  1. Asosiy ekranning yuqorisidagi Add (Qoʻshish) ni bosing, keyin yuqori chap tugma bilan oʻzgartirmoqchi boʻlgan yozuv turini tanlang.

  2. Cards (Kartalar) ni bosing.

  3. Bezak boʻlimining pastiga (oxirgi "}" belgisidan keyin) quyidagi matnni qoʻshing, "_arial.ttf" ni media papkangizga nusxalagan faylingiz nomi bilan almashtirib:

@font-face {
    font-family: myfont;
    src: url("_arial.ttf");
}

Faqat "arial" qismini oʻzgartiring, "myfont" qismini emas.

Shundan keyin butun karta uchun yoki alohida maydonlar uchun shriftni oʻzgartirishingiz mumkin. Butun karta uchun shriftni oʻzgartirish uchun .card boʻlimidagi font-family: qatorini topib, shriftni "myfont" ga oʻzgartiring. Faqat baʼzi maydonlar uchun shriftni oʻzgartirish uchun yuqoridagi Maydonlarni bezash yoʻriqnomasiga qarang.

Fayl nomlari aynan mos kelishiga ishonch hosil qiling. Fayl nomi arial.TTF boʻlsa-yu, karta shablonlaringizda arial.ttf deb yozsangiz, ishlamaydi.

Tungi rejim

Sozlamalar oynasida tungi rejim yoqilganda shablonlar qanday koʻrinishini sozlashingiz mumkin.

Ochroq kulrang fon xohlasangiz, quyidagiga oʻxshash narsadan foydalanishingiz mumkin:

.card.nightMode {
    background-color: #555;
}

"myclass" uslubingiz boʻlsa, quyidagi tungi rejim yoqilganda matnni sariq rangda koʻrsatadi:

.nightMode .myclass {
    color: yellow;
}

Soʻnish va aylantirish

Anki standart holatda javobga avtomatik aylantiradi. U id=answer boʻlgan HTML elementini qidiradi va shu yergacha aylantiradi. Aylantirish joyini oʻzgartirish uchun id'ni boshqa elementga qoʻyishingiz yoki aylantirishni oʻchirish uchun id=answer ni olib tashlashingiz mumkin.

Kartaning savol tomoni standart holatda asta-sekin paydo boʻladi (fade in). Bu kechikishni oʻzgartirmoqchi boʻlsangiz, old tomon shabloningiz tepasiga quyidagini qoʻyishingiz mumkin:

<script>
    qFade = 100;
    if (typeof anki !== "undefined") anki.qFade = qFade;
</script>

100 (millisekund) standart qiymat; soʻnishni oʻchirish uchun 0 ga qoʻying.

Javascript

Anki kartalari veb-sahifalar kabi koʻriladi, shuning uchun karta shabloni orqali kartalaringizga baʼzi Javascript kodlarini joylash mumkin. Yaxshi manba sifatida forumdagi ushbu yozuvni oʻqing.

Javascript ilgʻor imkoniyat boʻlgani va juda koʻp narsa xato ketishi mumkinligi uchun Javascript imkoniyati hech qanday yordamsiz va kafolatsiz taqdim etiladi. Biz Javascript yozishda yordam bera olmaymiz va yozgan kodingiz Anki'ning kelgusi yangilanishlarida oʻzgartirishsiz ishlashda davom etishini kafolatlay olmaymiz. Duch kelgan muammolarni oʻzingiz hal qilishga qulay boʻlmasangiz, Javascript'dan foydalanmang.

Har bir Anki klienti karta koʻrinishini boshqacha amalga oshirishi mumkin, shuning uchun xulq-atvorni platformalar boʻylab sinab koʻrishingiz kerak. Bir qancha klientlar uzoq ishlaydigan veb-sahifani saqlab, kartalar takrorlanganda uning qismlarini dinamik ravishda yangilash orqali amalga oshirilgan, shuning uchun Javascript kodingiz document.write() kabi narsalarni qilish oʻrniga document.getElementById() kabi narsalar yordamida hujjat qismlarini yangilashi kerak.

window.alert kabi funksiyalar mavjud boʻlmasligi mumkin. Anki javascript xatolarini terminalga yozadi, shuning uchun ularni koʻrish uchun konsolni koʻrishingiz kerak. JavaScript bilan bogʻliq muammolarni aniqlash uchun Chrome'ning inspektoridan foydalanishingiz mumkin.
