Kompyuter qoʻllanmasi

Eksport qilish

Eksport kolleksiyangizning bir qismini matnli fayl yoki paketlangan Anki toʻplami sifatida saqlash imkonini beradi. Eksport qilish uchun File (Fayl) menyusini bosib, Export (Eksport) ni tanlang.

Text Files (Matnli fayllar)

"Notes in Plain Text" (Oddiy matndagi yozuvlar) ni tanlasangiz, Anki yozuvlar mazmunini matnli faylga yozadi. Har bir maydon tab bilan ajratiladi. Hosil boʻlgan faylni tahrirlab, birinchi maydonni oʻzgartirmasangiz, keyinroq uni Anki'ga qayta import qilishingiz mumkin va Anki yozuvlaringizni tahrirlaringizga qarab yangilaydi, faqat bunda ular oʻsha yozuv turiga qayta import qilinishi kerak.

Birinchi maydonni ham tahrirlashingiz kerak boʻlsa, yozuv turingiz formatini oʻzgartirishingiz kerak boʻladi, shunda birinchi maydon haqiqiy matn emas, ID raqami boʻladi. (Buni osonlashtirish uchun Add note id qoʻshimchasini oʻrnatishingiz mumkin.)

Matnni qayta import qilganingizda formatlash saqlanib qolishi uchun, matn barcha HTML formatlash bilan birga eksport qilinadi.

Packaged Decks (Paketlangan toʻplamlar)

"Paketlangan toʻplam" kartalar, yozuvlar, yozuv turlari va barcha tovush yoki rasmlarni .apkg yoki .colpkg bilan tugaydigan bitta faylga joylashtiradi. Paketlangan toʻplamlardan kartalarni odamlar oʻrtasida almashish yoki kolleksiyangizning qismlarini zaxiralash uchun foydalanishingiz mumkin.

Paketlangan toʻplamlarning ikki xil turi bor.

Collection (.colpkg) (Kolleksiya)

.colpkg — "Anki Collection Package" (Anki kolleksiya paketi) degani. Uni eksport qilsangiz, butun kolleksiyangiz eksport qilinadi. Kolleksiyada rejalashtirish maʼlumotlari bilan birga barcha toʻplamlar bor. Kolleksiya paketidan kolleksiyangizni zaxiralash yoki boshqa qurilmaga nusxalash uchun foydalanishingiz mumkin.

Anki'ning oldingi versiyalarida yaratilgan kolleksiya paketlari collection.apkg deb atalgan.

What Happens on Import? (Import qilinganda nima boʻladi?)

.colpkg faylni import qilsangiz, Anki'dagi hozirgi barcha kartalaringiz oʻchiriladi va .colpkg fayldagi kartalar bilan almashtiriladi. Bu kolleksiyangizni qurilmalar oʻrtasida oldinga-orqaga nusxalash uchun foydali.

Kolleksiyangizdagi mavjud media kolleksiya paketi import qilinganda oʻchirilmaydi. Ishlatilmayotgan mediani oʻchirish uchun Tools > Check Media (Asboblar > Mediani tekshirish) dan foydalaning.

Export Options (Eksport sozlamalari)

Include Media (Mediani kiritish)

Belgilansa, mahalliy media kiritiladi. Belgilanmasa, .colpkg tarkibida audio, rasm yoki boshqa media boʻlmaydi.

Support older Anki versions (slower/larger files) (Anki'ning eski versiyalarini qoʻllab-quvvatlash (sekinroq/kattaroq fayllar))

Belgilansa, faylning eski versiyasi yaratiladi. Eski klientlarni qoʻllab-quvvatlashingiz kerak boʻlsa, buni yoqing. Belgilanmasa, faylning zamonaviy versiyasi yaratiladi. Import va eksport tezroq boʻladi, media fayllar siqiladi, lekin hosil boʻlgan faylni Anki'ning eski klientlari oʻqiy olmaydi.

Deck (.apkg) (Toʻplam)

.apkg — "Anki Deck Package" (Anki toʻplam paketi) degani. Undan bitta toʻplamni (va uning har qanday ichki toʻplamlarini) eksport qilish uchun foydalanishingiz mumkin.

Fayl nomi collection.apkg boʻlsa, bu oʻrniga kolleksiya paketi hisoblanadi. .apkg bilan tugaydigan barcha boshqa fayl nomlari toʻplam paketlari hisoblanadi.

What Happens on Import? (Import qilinganda nima boʻladi?)

Toʻplam paketini import qilganingizda, Anki mazmunni kolleksiyangizni ustidan yozish oʻrniga unga qoʻshadi.

Toʻplam paketidagi baʼzi yozuvlar avval import qilingan boʻlsa, Anki eng oxirgi oʻzgartirish vaqtiga ega versiyani saqlaydi.

Sizda Biology nomli toʻplam bor va u Anki'da ishlatilmoqda. Endi siz shu toʻplamning yangilangan versiyasini yuklab olasiz. Yangilangan toʻplamni import qilsangiz, Anki barcha tahrirlarni oʻz kolleksiyangizga qoʻshib oladi.

Oʻzgartirilmagan .apkg ni oʻz kolleksiyangizda oʻzgarishlar qilganingizdan keyin (masalan, kartalarni tahrirlaganingizdan keyin) qayta import qilsangiz, Anki oʻzgarishlaringizni ustidan yozish oʻrniga kolleksiyangizda saqlab qoladi.

Export Options (Eksport sozlamalari)

Include Scheduling Information (Rejalashtirish maʼlumotlarini kiritish)

Belgilansa, takrorlash tarixingiz kabi rejalashtirish maʼlumotlari eksport qilinadi. Belgilanmasa, Anki toʻplamni boshqa odamlar bilan ulashayapsiz deb hisoblaydi va marked hamda leech teglari bilan birga butun rejalashtirish maʼlumotlarini olib tashlaydi. Shunda foydalanuvchilar toʻplamingizning toza nusxasiga ega boʻladi.

Include Deck Presets (Toʻplam presetlarini kiritish)

Belgilansa, toʻplam presetlari kiritiladi.

Include Media (Mediani kiritish)

Belgilansa, mahalliy media kiritiladi. Belgilanmasa, .apkg tarkibida audio, rasm yoki boshqa media boʻlmaydi.

Support older Anki versions (slower/larger files) (Anki'ning eski versiyalarini qoʻllab-quvvatlash (sekinroq/kattaroq fayllar))

Belgilansa, faylning eski versiyasi yaratiladi. Eski klientlarni qoʻllab-quvvatlashingiz kerak boʻlsa, buni yoqing. Belgilanmasa, faylning zamonaviy versiyasi yaratiladi. Import va eksport tezroq boʻladi, media fayllar siqiladi, lekin hosil boʻlgan faylni Anki'ning eski klientlari oʻqiy olmaydi.
